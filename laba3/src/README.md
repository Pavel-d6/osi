# Лабораторная работа №3, вариант 6

Перемножение двух матриц, содержащих комплексные числа, в многопоточном режиме.

## Задача

Даны матрицы A (N×M) и B (M×K), элементы которых комплексные числа. Нужно получить матрицу C (N×K) = A · B. Вычисление распараллелено между потоками операционной системы. Максимальное число потоков задаётся ключом запуска.

## Данные

**Комплексное число** хранится структурой из двух полей типа `double`:

```c
typedef struct {
    double re, im;
} Complex;
```

**Матрицы** хранятся одномерными массивами `Complex` по строкам. Память выделяется через `malloc`, поэтому размеры задаются при запуске. Индекс элемента:

| Матрица | Размер | Элемент [i][j] |
|---|---|---|
| A | N×M | `A[i * M + j]` |
| B | M×K | `B[i * K + j]` |
| C | N×K | `C[i * K + j]` |

**Входные данные** генерируются в программе: `srand(1)` и случайные значения от -1 до 1 для вещественной и мнимой частей. Фиксированное начальное значение генератора даёт одинаковые матрицы при каждом запуске.

## Алгоритм

Элемент результата:

```
C[i][j] = Σ A[i][k] · B[k][j],  k = 0 .. M-1
```

Произведение комплексных чисел `(a + bi)(c + di)`:

```
вещественная часть: a·c − b·d
мнимая часть:       a·d + b·c
```

Сумма накапливается в локальных переменных `sum_re` и `sum_im`, в `C` результат записывается один раз после внутреннего цикла. Сложность алгоритма O(N·M·K).

## Распараллеливание

Строки результирующей матрицы C делятся между потоками на непрерывные диапазоны.

- Для расчёта строки `i` матрицы C нужны строка `i` матрицы A и вся матрица B.
- A делится по строкам, C делится так же, B не делится: все потоки читают одну и ту же B из общей памяти.
- Каждый поток пишет только в свои строки C. Диапазоны не пересекаются, поэтому гонок данных нет и мьютексы не требуются.

### Задание потока

Функция потока принимает один указатель `void *`, поэтому параметры упакованы в структуру:

```c
typedef struct {
    const Complex *A, *B;
    Complex *C;
    int M, K;
    int row_begin;   // первая строка потока
    int row_end;     // конец диапазона, не включая
} Task;
```

У всех потоков одинаковые `A`, `B`, `C`, `M`, `K`. Различаются только `row_begin` и `row_end`.

### Распределение строк

Пусть p потоков, N строк.

```
base = N / p
rest = N % p
поток i получает base + (i < rest ? 1 : 0) строк
```

Остаток от деления раздаётся первым потокам по одной строке, поэтому нагрузка различается не более чем на одну строку. Пример: N = 10, p = 4 даёт 3 + 3 + 2 + 2.

### Число потоков

Ключ `-t` задаёт максимум. Реальное число потоков `p = min(t, N)`: потоков больше, чем строк, не создаётся.

## Ход выполнения программы

1. Разбор ключей запуска (`getopt`), проверка параметров.
2. Выделение памяти под A, B, C.
3. Заполнение A и B случайными числами.
4. Вычисление `p` и создание массивов `tid` (идентификаторы потоков) и `tasks` (задания).
5. Цикл создания: для каждого потока заполняется `Task` и вызывается `pthread_create(&tid[i], NULL, worker, &tasks[i])`. Потоки начинают работать сразу.
6. Цикл ожидания: `pthread_join(tid[i], NULL)` для каждого потока. Основной поток блокируется, пока все потоки не завершатся.
7. Вывод числа запущенных потоков и элемента `C[0][0]`.
8. Освобождение памяти.

## Синхронизация

Единственная точка синхронизации это `pthread_join`. После возврата из `join` для всех потоков результаты в C гарантированно записаны.

Два требования корректности:

- Массив `tasks` создаётся заранее и существует до конца работы потоков. Потоки читают из него уже после завершения цикла создания, поэтому передавать адрес локальной переменной цикла нельзя.
- Создание и ожидание выполняются в **разных** циклах. Если вызывать `join` сразу после `create` в одном цикле, потоки выполнятся последовательно.

## Функции

| Функция | Назначение |
|---|---|
| `worker(void *arg)` | функция потока: считает строки из диапазона `[row_begin, row_end)` |
| `fill_random(Complex *X, int count)` | заполняет массив случайными комплексными числами |
| `main` | разбор ключей, подготовка данных, создание и ожидание потоков |

## Ключи запуска

| Ключ | Значение | По умолчанию |
|---|---|---|
| `-t` | максимальное число потоков | 1 |
| `-n` | число строк A (и C) | 500 |
| `-m` | число столбцов A и строк B | равно `-n` |
| `-k` | число столбцов B (и C) | равно `-n` |

Если `-m` и `-k` не заданы, матрицы квадратные.

## Сборка и запуск

```bash
gcc -O2 -pthread lab3.c -o lab3

./lab3 -t 4 -n 500                 # квадратные 500×500, до 4 потоков
./lab3 -t 4 -n 300 -m 800 -k 200   # A: 300×800, B: 800×200, C: 300×200
```

## Вывод

```
Запущено потоков: 4
C[0][0] = -3.412870 + 5.021346i
```

Первая строка показывает реальное число потоков. Вторая строка печатает один элемент результата для проверки того, что вычисление выполнено.
